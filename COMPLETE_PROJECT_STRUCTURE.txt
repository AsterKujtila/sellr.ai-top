DATABASE SCHEMA (PostgreSQL via Supabase)
═══════════════════════════════════════════════════════════════════════════════════

TABLES:

1. profiles (UUID primary key)
   ├── id (FK auth.users)
   ├── name
   ├── email
   ├── avatar_url
   ├── whop_store_url
   ├── plan (free/starter/pro/scale)
   ├── credits_used
   ├── credits_limit
   ├── onboarding_completed
   ├── created_at
   └── updated_at

2. chat_sessions (UUID primary key)
   ├── id
   ├── user_id (FK profiles)
   ├── title
   ├── session_date
   ├── day_of_week
   ├── summary
   ├── created_at
   └── updated_at (auto-update trigger)

3. messages (UUID primary key)
   ├── id
   ├── session_id (FK chat_sessions)
   ├── user_id (FK profiles)
   ├── role (user/assistant)
   ├── content
   └── created_at

4. feedback (UUID primary key)
   ├── id
   ├── user_id (FK profiles)
   ├── reason (bug/suggestion/other)
   ├── message
   └── created_at

API ENDPOINTS (All require auth)
═══════════════════════════════════════════════════════════════════════════════════

POST /api/chat
  → Request: { messages: [{role, content}][], sessionId: string }
  → Response: { text: string }
  → Cost: 1 credit
  → Error: 429 if out of credits

POST /api/offers
  → Request: { product, audience, outcome?, price?, style }
  → Response: { text: string }
  → Cost: 2 credits

POST /api/store
  → Request: { url?, description }
  → Response: { text: string }
  → Cost: 3 credits

GET /api/chat/history?sessionId=xxx
  → Response: { messages: Message[] }

GET/POST/PATCH/DELETE /api/sessions
  → Full CRUD for chat sessions

POST /api/feedback
  → Request: { reason, message }

DELETE /api/account/delete
  → Cascading delete of profile + all related data
