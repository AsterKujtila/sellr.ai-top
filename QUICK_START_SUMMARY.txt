                               QUICK START GUIDE
═══════════════════════════════════════════════════════════════════════════════════

STEP 1: CLONE AND INSTALL (5 minutes)
────────────────────────────────────────────────────────────────────────────────

$ git clone <repo-url> && cd sellr-ai
$ npm install

STEP 2: SETUP SUPABASE (10 minutes)
────────────────────────────────────────────────────────────────────────────────

1. Go to supabase.com → Create new project
2. Copy project URL & Anon Key
3. In Supabase dashboard:
   - Go to SQL Editor
   - Copy entire content of: supabase/migrations/001_schema.sql
   - Paste and execute
4. Setup Google OAuth:
   - Auth → Providers → Google
   - Enable PKCE method
   - Add redirect URL: http://localhost:3000/auth/callback (dev)
   - Add production URL when ready

STEP 3: GET ANTHROPIC API KEY (2 minutes)
────────────────────────────────────────────────────────────────────────────────

1. Go to console.anthropic.com
2. Create API key
3. Copy it

STEP 4: CONFIGURE ENVIRONMENT (2 minutes)
────────────────────────────────────────────────────────────────────────────────

Create .env.local:

  NEXT_PUBLIC_SUPABASE_URL=https://[project].supabase.co
  NEXT_PUBLIC_SUPABASE_ANON_KEY=[your-anon-key]
  ANTHROPIC_API_KEY=sk-ant-[your-key]

STEP 5: RUN LOCALLY (1 minute)
────────────────────────────────────────────────────────────────────────────────

$ npm run dev

Open http://localhost:3000 in browser
- Click "Continue with Google"
- Test chat, offers, store features

STEP 6: DEPLOY TO VERCEL (3 minutes)
────────────────────────────────────────────────────────────────────────────────

$ vercel deploy

Or via GitHub:
1. Push to GitHub
2. Go to vercel.com → Import project
3. Select repo
4. Set environment variables (same as .env.local)
5. Deploy

Total setup time: ~20 minutes
